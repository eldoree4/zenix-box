# Store release metadata and checklist

This folder stores public store metadata placeholders to be customized before final submission.

- `store-metadata/google-play/description.md`
- `store-metadata/app-store/description.md`

Populate the following before publishing:

- app icon and splash asset
- screenshots for all device sizes
- privacy policy URL
- support URL / email
- app category and content rating
- localized description for languages you support
- final terms and app access flow
